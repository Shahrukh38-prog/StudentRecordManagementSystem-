# StudentRecordManagementSystem-
Student Record Management system developed using C++
Student Record Management System

Project Description

The Student Record Management System is a C++ based application designed to manage student records efficiently. It allows users to add, update, delete, and manage student information.

Features

* Add new student records
* Update existing student records
* Delete student records
* Save student information
* Display student records

Technologies Used

* C++
* File Handling
* QT

Project Files

* main.cpp – Main source code
* students.txt – Stores student records
* Student Record Management System.exe – Executable application

How to Run

1. Download or clone the repository.
2. Open main.cpp in a C++ IDE.
3. Compile and run the program.
